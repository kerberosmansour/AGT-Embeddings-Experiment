# Lessons Learned - agtrt-v2 Milestone 2

## What changed
- Generated a deterministic 240-row suite from the existing 24 seed scenarios.

## Assumptions verified
- Six trap classes can each support a 40-row core cell: 8 canonical positives, 16 evasion positives, 8 hard-benign negatives, and 8 near-miss negatives.

## Rules for the next milestone
- Do not call 240 exhaustive in an absolute sense; call it the core measurement suite and allow extension packs for underpowered metric cells.
