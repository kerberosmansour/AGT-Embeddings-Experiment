# Lessons — agtrt M4

- **Stacked-branch base matters.** M4 appends to `run-smoke.sh`, which is created in M3 (#26, unmerged). Branching M4 off the canonical branch (which lacked run-smoke.sh) was wrong; re-based onto `slo/agtrt-m3`. Untracked new files (`scorecard.py`, `controls/agt-ac.csv`, `test_reporter.py`) persisted across the `git checkout`, so no work lost. Rule: base milestone N's branch on N-1's branch until the chain merges.
- **"Evidence, not certification" trips naive overclaim greps.** The disclaimer literally says "not a certification … not a pass/fail badge", so a grep for `badge`/`certification` false-positives on the negation. The real no-overclaim test scans for POSITIVE claim terms (`certified`, `owasp-certified`, `official opencre`) — scan for the assertion, not the word.
- **s6 was data-only (no script).** Unlike s1/s4, s6 had only `scorecard_report.json` + `sample_results.jsonl`, so M4 built `scorecard.py` from scratch to MATCH that output shape (certification_claim, controls, evidence_levels, trap_classes, status, remediation) + added the honest fields (`unmapped_controls`, `failures`).
- **`--from-scenarios` keeps the smoke self-contained.** Rather than wiring per-scenario harness runs, the reporter projects the 24 validated scenarios into L2 result rows for the smoke chain — a deterministic, raw-free end-to-end report over all 24.
