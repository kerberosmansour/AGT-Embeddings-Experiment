# Lessons — agtrt M6

- **The sandbox is the milestone.** M6's value isn't "call a model" — it's proving an unsafe live action is *contained*. A Python-level guard is bypassable by a subprocess; the OS namespace (`bwrap --unshare-all`) is not. Proven: a real subprocess can't reach the internet OR `169.254.169.254` (the AWS-metadata SSRF target, CWE-918). mac's macOS couldn't provide this (no Docker daemon/netns); Linux could — **platform matters for security controls.**
- **Separate the trusted model call from the sandboxed tool execution.** Keys live with the trusted orchestrator (outside the sandbox); the model's chosen tool runs *inside* the no-net/no-fs/scrubbed jail. So the secret is never exposed to the (potentially hostile) tool, and the tool can't act for real. This split is what makes a live red-team assessment safe.
- **usr-merge breaks naive bwrap binds.** This Arch box has no `/lib64` and `/lib`→`usr/lib`; `--ro-bind /lib64` fails. Use `--ro-bind /usr /usr` + `--symlink usr/lib /lib` (and /lib64,/bin,/sbin). Portable across usr-merged distros.
- **A successful model call can still be vacuous.** The first keyed run with the current model reached Anthropic but produced zero tool traces because the committed smoke scenario only contained a placeholder. M6 now has `--require-trace` and a non-secret oc-6 live probe so a keyed run cannot pass without at least one real model tool decision.
- **Model IDs age.** The original cheap default (`claude-3-5-haiku-latest`) returned HTTP 404 on 2026-06-19. The adapter now defaults to `claude-haiku-4-5`, and `AGTRT_LIVE_MODEL` can override the smoke model without code changes.
- **mac fail-closed correctly; Linux finished the proof.** macOS could not provide bwrap/netns, so it refused to fake a sandbox. Linux/Omarchy then provided the OS boundary and emitted the real `L3_live` trace. Verify-don't-trust + fail-closed beat a green-looking-but-insecure milestone.
